# Петелька

Учебный сайт о вязании, созданный на HTML5, CSS3 и JavaScript без фреймворков.

## Страницы
- `index.html` — главная.
- `catalog.html` — каталог из 9 изделий, поиск, фильтрация и подробности каждого проекта.
- `helper.html` — счётчик рядов с сохранением в localStorage и калькулятор петель.
- `about.html` — о проекте.

## Запуск
Откройте файл `index.html` в браузере. Установка и сервер не нужны.

## Реализовано
Закреплённая шапка, навигация между страницами, кнопка «Наверх», текстовый логотип и копирайт в подвале, адаптация под разные размеры экрана. Все иллюстрации находятся локально в папке `images/` в формате SVG.

*Описания вязания представлены в сокращённом учебном формате, а не как полные технические схемы по размерам.*
